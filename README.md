# portfolio-website-noir

My personal portfolio. It's a single page styled as a rainy 90s night on a VHS tape.

The page is made of these sections:

- **Intro:** a VCR boot screen
- **Hero:** a neon sign under a street lamp in the rain
- **About:** a newspaper front page
- **Work and projects:** an arcade stage select
- **Drink break:** a 3D glass you can pour
- **Skills:** a jukebox
- **Contact:** an answering machine, a pager and a hiring poster

## Built with

- Next.js 15 and React 19
- TypeScript
- Tailwind CSS 4 and plain CSS
- three.js and React Three Fiber 

## Running it locally

You need Node.js 18.18 or later and pnpm.

```bash
pnpm install
pnpm dev
```

Then open http://localhost:3000.

To make a production build:

```bash
pnpm build
pnpm start
```
